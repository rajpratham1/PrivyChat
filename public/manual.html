1. Getting Started

PrivyChat is designed to be as simple as it is secure. When you open the application, you are presented with three distinct ways to communicate.

🔒 Mode A: 1-on-1 Secure Link

This is the most secure method for creating a private conversation with exactly one other person.

  • How it works: The system generates a unique, encrypted URL containing a special key.
  • Security: The encryption key is in the URL hash (after the #). This part of the URL is never sent to the server, meaning even the server admin cannot peek at your chat.
  • Sharing: Copy the link and send it via a secure channel (Signal, Email, etc.) to your partner.

🔑 Mode B: Private Room

Best for recurring meetings or small groups who know a shared secret.

  • Setup: You create a Room Name (e.g., "OperationAlpha") and a Password.
  • Encryption: The app uses the password to mathematically derive an encryption key (using PBKDF2).
  • Warning: If you forget the password, all data is lost. There is no password recovery.

📢 Mode C: Public Lobby

A global, open chat room. Use this for casual testing. Messages are still transported securely via HTTPS, but they are accessible to anyone who joins the "General" room.

⚠️ IMPORTANT: PrivyChat uses RAM-Only Storage. If you refresh the page or the server restarts, your chat history is permanently deleted. Do not use this for long-term storage of information.

2. Spy Tools & Stealth Features

This is where PrivyChat shines. We have built-in tools to protect you in the physical world.

🎭 Stealth Mode (Calculator)

Need to hide what you are doing instantly? Turn your chat into a harmless Calculator.

  • Activate: Click the Mask Icon 🎭 in the top-right header.
  • Effect: The chat interface is immediately replaced by a fully functional scientific calculator.
  • To Unlock: Enter the secret code and press Equals =.
CODE: 1337

👻 Ghost Mode

Prevents "Shoulder Surfing" (people behind you reading your screen).

  • Activate: Click the Ghost Icon 👁️ / 👻.
  • Effect: All messages become heavily blurred.
  • Reveal: Hover your mouse cursor over a specific message to reveal it temporarily.

🚨 Panic Button

The "Nuclear Option" for emergencies.

  • Activate: Click the Siren Icon 🚨.
  • Effect:
    1. Immediately saves nothing.
    2. Disconnects from the server.
    3. Wipes all local browser storage.
    4. Redirects the browser to Google.com instantly.

🌦️ Decoy Vault (Fake Login)

Need to prove you aren't chatting? Use the Decoy Vault.

  • How to use: In the "Room Code" input, type weather or guest and hit Enter.
  • Effect: You are instantly redirected to a fully functional Weather App.
  • Why: Plausible Deniability. You can show anyone that you were just checking the forecast.

3. Messaging & Media

💣 Self-Destruct Timer

Want your messages to disappear after being read?

  • Use the dropdown menu next to the input bar (Default: ⏱️ Off).
  • Select 5s, 10s, or 30s.
  • Sent messages will display a countdown timer on the recipient's screen and vanish when it hits zero.

🎤 Voice Notes

  • Press and hold the Pink Microphone Button 🎤.
  • Speak your message.
  • Release the button to send automatically.
  • Voice notes are encrypted using Opus/WebM format for high quality.

📎 File Encryption

You can send images and documents. Before leaving your device, every byte is encrypted. The server only sees random noise.

4. Troubleshooting

Microphone Not Working?
Make sure you have allowed "Microphone Access" in your browser's site settings.
(Click the Lock icon in the address bar -> Site Settings -> Microphone -> Allow)
Encryption Error?
If you see "Decryption Failed" messages, it means your partner has a different password or key than you. Ensure you both joined with the exact same password.
