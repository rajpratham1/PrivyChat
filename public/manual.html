1. Getting Started: The "Search Engine" Interface

PrivyChat disguises itself as a simple search engine. Here is how to navigate the "Google Theme" UI to access different modes.

🌍 Public Lobby (Group Chat)

Want to join the global conversation?

  • Action: Leave the search bar empty and click the button.
  • Result: You enter the "General" room. Anyone can join here.
  • Security: Encrypted in transit (HTTPS), but not end-to-end encrypted. Public by design.

🔐 Private Room (Password Protected)

For secure team meetings or group chats.

  • Action: Click or type a Room Name in the search bar and hit Enter.
  • Setup: You will be prompted to set a Password.
  • Encryption: Uses AES-GCM (military-grade). The password generates the key. If you lose the password, the data is unrecoverable.

🎲 1-on-1 Secure Link ("I'm Feeling Lucky")

The gold standard for top-secret conversations.

  • Action: Click the button.
  • Result: Instantly generates a unique, 1-time room (e.g., secure-x8a92b).
  • Sharing: Copy the URL and send it to your partner. The encryption key is hidden in the URL hash, so the server never sees it.
⚠️ IMPORTANT: PrivyChat uses RAM-Only Storage. If you refresh the page or the server restarts, your chat history is permanently deleted.

PrivyChat includes "James Bond" style features to protect you in the physical world.

  • Effect: You are instantly redirected to a fully functional harmless Weather App.
  • Why: Plausible Deniability.

CODE: 1337

👻 Ghost Mode

Prevents "Shoulder Surfing" (people behind you reading your screen).

  • Activate: Click the Eye Icon 👁️ in the chat header.
  • Effect: All messages are blurred. Hover over a single message to read it.

🕵️‍♂️ Operation Invisible Ink (Steganography)

A true spy tool. Hide secret text messages inside innocent files.

  • Encode (Hide): Click the Spy Icon 🕵️‍♂️ -> Drag a PNG image -> Type your secret -> Download the new "Secret Image".
  • Decode (Read): Click the Spy Icon 🕵️‍♂️ -> Go to "Read Message" -> Upload the "Secret Image" -> Reveal the text.
  • Note: Works best with PNG files. Sharing via WhatsApp/Facebook may destroy the hidden data due to compression.

🎭 Protocol: Matrix (Visual Polish)

Immersive visual effects to make you feel like a movie hacker.

  • Hacker Typing: Received messages "decode" character-by-character (H... X... He... Hello).
  • Visual Self-Destruct: When a timer is set, messages physically burn away or glitch out of existence instead of just vanishing.

🚨 Panic Button

The "Nuclear Option" for emergencies.

  • Activate: Click the Red Siren Icon 🚨.
  • Effect: Disconnects, Wipes RAM, Clears Storage, and Redirects to Google.com immediately.

3. Messaging & Media

💣 Self-Destruct Timer

Want your messages to disappear after being read?

  • Use the dropdown menu next to the input bar (Default: ⏱️ Off).
  • Select 5s, 10s, or 30s.
  • Sent messages will display a countdown timer on the recipient's screen and vanish when it hits zero.

🎤 Voice Notes

  • Press and hold the Pink Microphone Button 🎤.
  • Speak your message.
  • Release the button to send automatically.
  • Voice notes are encrypted using Opus/WebM format for high quality.

You can send images and documents. Before leaving your device, every byte is encrypted. The server only sees random noise.

📞 Secure Calls (WebRTC)

PrivyChat supports direct Peer-to-Peer (P2P) calling. No central server processes your audio or video.

  • Voice Call (📞): Audio only. Great for low bandwidth or privacy.
  • Video Call (🎥): High-definition video + audio.
  • Encryption: Uses DTLS-SRTP standard keys. The connection is direct between you and your partner.
  • Permissions: You must allow Camera/Microphone access when prompted.

4. Troubleshooting

Microphone Not Working?
Make sure you have allowed "Microphone Access" in your browser's site settings.
(Click the Lock icon in the address bar -> Site Settings -> Microphone -> Allow)
Encryption Error?
If you see "Decryption Failed" messages, it means your partner has a different password or key than you. Ensure you both joined with the exact same password.
